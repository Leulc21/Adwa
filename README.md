# Adwa - Creative Agency 
## 🦁 Lion of Judah – AI Generated Graphic Design

A culturally-inspired graphic design project that fuses the iconic symbol of the Lion of Judah with modern AI artistry and fluid web animations. Built with HTML, CSS, and JavaScript, and powered by Vite for lightning-fast development.

## 🔥 Features

- 🎨 AI-generated graphics centered on the Lion of Judah theme  
- ⚡ Fast bundling and dev server with [Vite](https://vitejs.dev/)  
- 🎬 Smooth animations using [GSAP](https://greensock.com/gsap/)  
- 💡 Lightweight, responsive, and mobile-friendly layout  
- 🧼 Clean Vanilla JS with no frameworks

## 🛠 Tech Stack

- HTML5  
- CSS3  
- JavaScript (ES6)  
- Vite  
- GSAP (GreenSock Animation Platform)
